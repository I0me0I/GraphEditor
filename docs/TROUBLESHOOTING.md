# GraphEditor

一个用于编辑图论中的图（顶点与边）的 Windows 桌面程序，界面类似画图工具。

- 目标框架：.NET Framework 4.8（Windows 10 / 11 自带）
- 界面技术：Windows Forms，工作区为自绘画布
- 构建方式：使用系统自带的 C# 编译器（`csc.exe`），**无需安装 .NET SDK**
- 自定义文件格式：`.graph`（JSON 文本，可直接阅读与版本管理）
- 导出格式：SVG 矢量图

---

## 1. 快速开始

```powershell
# 构建（产物在 build\GraphEditor.exe）
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

# 运行
.\build\GraphEditor.exe
```

构建脚本会自动：定位 `csc.exe`、嵌入应用图标、把 `README.md` 一并复制到输出目录。

运行自检（219 项断言，全部通过时退出码为 0）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-tests.ps1
```

可选：把 `.graph` 关联到本程序（只写入 `HKCU`，不需要管理员权限）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\register-filetype.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools\register-filetype.ps1 -Unregister   # 取消关联
```

之后双击 `.graph` 文件即可用 GraphEditor 打开（程序支持从命令行接收文件路径）。

## 3. 工作区操作

### 视图

| 操作 | 方式 |
| --- | --- |
| 缩放 | 鼠标滚轮（以光标位置为锚点，10% ~ 800%） |
| 平移 | 在空白处（或边上）按住**右键**拖动（起手延迟仅 50ms，与 draw.io 一致） |
| 连线 | **在顶点上右键按住拖动**到另一个顶点后松开（见下节） |
| 滚动 | 内容超出工作区时自动出现横向/纵向滚动条（方向见下） |
| 适应窗口 | 视图菜单「适应窗口」，或 Ctrl+9 |
| 实际大小 | 视图菜单「实际大小」，或 Ctrl+1 |
| 回到原点 | 视图菜单「回到原点」 |
| 居中显示内容 | 视图菜单「居中显示内容」 |

> **滚动条方向**：与 Windows 记事本/浏览器一致 —— **向下拖垂直滚动条，看到内容下方的部分**（内容向上移动）。
> 滚到底时视口底边正好到内容底边，不会出现「整片空白」。

### 画布：无限平面（参考 draw.io）

画布没有边界、也没有需要维护的尺寸，整个工作区就是绘制面，元素可以落在任意坐标上：

- **坐标系**：原点默认位于客户区中心，**x 向右为正，y 向下为正**（与 `.graph` 文件里的坐标一致）。
  因此原点左上方是负坐标，程序不限制坐标范围。
- **初始视图**：空图时视图原点正好在客户区中心，即世界原点 `(0,0)` 显示在正中央。
- **没有纸张、没有边框**：整个工作区都是白色画布，不再绘制纸张矩形与阴影。
- **滚动条随内容出现**：内容全部在视野内时**不显示**滚动条（与 draw.io 一致）；内容超出视口时自动出现，
  可滚动范围随内容外接矩形变化，并始终在内容外侧留出约一个视口的余地，方便把内容移到视野中间。
- **视图菜单**：「回到原点」把 `(0,0)` 拉回屏幕中央；「居中显示内容」把图内容移到视野中央（打开文件时自动执行一次）。

### 选中

| 操作 | 方式 |
| --- | --- |
| 选中单个顶点或边 | 左键点击 |
| 多选 | 按住 Ctrl 左键点击，可混合选择顶点与边 |
| 框选 | 在空白处按住左键拖出矩形，**只有两个端点都被框中的边才会被选中** |
| 全选 | Ctrl+A 或编辑菜单「全选」 |
| 取消选择 | Esc 或编辑菜单「取消选择」 |
| 移动 | 按住左键拖动（选中的顶点一起移动，关联的边自动跟随） |
| 微调 | 方向键 1 像素，Shift+方向键 10 像素 |

> 框选边的规则与**复制/剪切的诱导子图**语义一致：顶点先按「是否被矩形碰到」选中，边再按「两个端点是否都已选中」决定。
> 所以只想选中某条边时，用左键直接点击它；框选只覆盖边中段（不含端点）不会选中该边。
| 删除 | Delete 或右键菜单「删除」 |

### 右键菜单

- **空白处**：新建顶点、全选、重置视图
- **顶点上**：重命名、颜色、删除（以及一条「按住右键拖动可连接到其他顶点」的操作提示）
- **边上**：重命名、颜色、删除
- **多选时**：颜色、删除（重命名会按序号批量命名）

### 建立连接（连边）

**在顶点上按住右键，拖动到另一个顶点，松开右键** —— 两个顶点之间即建立一条边。

- 拖动过程中从起点顶点到鼠标位置实时显示一条直线段，鼠标旁有操作提示
- 拖到某个顶点上时，该顶点会被绿色高亮环圈住、直线段变为实线，提示变为「松开右键：连接到 X」
- 松开在空白处 = 放弃（不会创建边）；拖动中按 **Esc** 也可取消
- 拖回起点顶点本身 = 创建**自环**
- 未拖动（原地按下再松开）仍然是弹出右键菜单，两种操作互不冲突
- 同一对顶点之间的多条边会自动弯曲分离；自环画成顶点右上方的小圆环
- 在**空白处**按住右键拖动仍然是平移画布

### 复制 / 剪切 / 粘贴

选中若干顶点（可同时选中边）后，用右键菜单或编辑菜单。菜单里**剪切排在复制之前**：

| 操作 | 快捷键 | 行为 |
| --- | --- | --- |
| 剪切 | Ctrl+X | 先按下面「复制」的规则复制，然后删除选中的顶点，**并删除所有与它们相连的边** —— 只连一个选中顶点的边也会一并删除 |
| 复制 | Ctrl+C | 复制**选中顶点集所诱导的子图**：选中的顶点 + 两端点都被选中的边（另外显式选中的边也包含） |
| 粘贴 | Ctrl+V | 把剪贴板内容放到当前视图中心，名字冲突时自动加编号，粘贴后自动选中新内容 |

剪贴板是应用内的（不写入系统剪贴板），因此在同一个程序中可以多次粘贴。

### 边名字的位置

边名字的锚点是**线段中点**，并沿**过该中点的法线**偏移：

| 位置 | 效果 |
| --- | --- |
| 内部 | 名字正中压在中点上 |
| 上方 / 下方 | 沿法线偏移约一个行高，文字沿边方向倾斜但始终正着读 |

顶点名字可放在内部 / 上方 / 下方 / 左侧 / 右侧（见「属性」菜单）。

### 旋转

选中一个或多个顶点后，用右键菜单「旋转」或编辑菜单「旋转」：

- 预设角度：顺时针 15° / 90° / 180°，逆时针 15° / 90°
- 「自定义角度」可输入任意度数，**正数为顺时针**
- 旋转围绕所选顶点的**中心**进行，只影响选中的顶点；未选中顶点之间的边不受影响

### 重命名

右键菜单「重命名」，或直接双击顶点 / 边。多选重命名时输入前缀，会依次编号（如 `X1`、`X2`…）。

### 着色

1. 先选中零个或多个顶点与边；
2. 右键菜单「颜色」，或编辑菜单里对应项，从 24 色中选一个颜色。

选中的顶点和边会统一改成该颜色。

### 属性菜单

每次展开时按当前画布状态重建，勾选状态实时反映现状。

| 子项 | 内容 |
| --- | --- |
| **顶点**（属性 → 顶点） | 颜色（调色盘，勾选当前色）、大小（8 / 10 / … / 60）、形状（圆形 / 方形）、**默认命名**（不命名 / 大写字母 / 字母V+数字）、**名字位置**（内部 / 上方 / 下方 / 左侧 / 右侧） |
| **边**（属性 → 边） | 颜色（调色盘，勾选当前色）、线宽（1 / 1.5 / … / 10）、线型（实线 / 虚线 / 点线）、**默认命名**（不命名 / 小写字母 / 字母e+数字 / 两端点名字）、**名字位置**（内部 / 上方 / 下方） |
| **图**（属性 → 图） | 多重图（关闭时删除多余的重边与自环）、有向图（关闭时隐藏箭头） |


#### 默认命名规则

命名规则只影响**新建**的顶点与边，不会重命名已有元素。默认值为：顶点 **大写字母**（`A`、`B`、`C`…），边 **不命名**。

| 规则 | 顶点得到 | 边得到 |
| --- | --- | --- |
| 不命名 | 无名字（不显示文字） | 无名字（不显示文字） |
| 字母（顶点：大写字母 / 边：小写字母） | `A`、`B` … `Z`，之后 `A1`、`B1` … | `a`、`b` … `z`，之后 `a1`、`b1` … |
| 前缀 + 数字（顶点：字母V+数字 / 边：字母e+数字） | `V1`、`V2`、`V3` … | `e1`、`e2`、`e3` … |
| 两端点名字（**仅边可用**） | —（顶点上退化为大写字母） | 两端点名字拼接，如 `AB`；重名加数字后缀，如 `AB2` |

- 取名时会跳过已存在的名字，所以手动改过名字之后不会产生重复（例如已有 `V1` 时下一个是 `V2`）。
- 边的「两端点名字」在**端点没有名字**时退回小写字母命名（`a`、`b`…），不会留空名。
- 早期版本的 `.graph` 文件把字母规则存为 `alphabetic`、前缀数字规则存为 `numeric`，两者都能正常读回。

> **样式语义**：顶点与边是两组独立的全局样式。**同一组内**所有元素的大小和样式完全相同；
> 只有**名字**和**颜色**可以逐个不同（单个元素用调色盘单独着色，或右键菜单改色）。
> 在「属性」里改动样式会立即作用于图中所有已存在的顶点 / 边。

## 6. 文件格式

### 6.1 `.graph`（自定义格式）

JSON 文本，UTF-8（无 BOM），带缩进，便于人工阅读与 diff。

```json
{
  "format": "GraphEditor.Graph",
  "version": "1.0",
  "canvas":      { "width": 900, "height": 640 },
  "vertexStyle": { "radius": 22, "shape": "circle", "defaultColor": "#2D7DD2",
                   "naming": "alphabetic", "labelPlacement": "inside" },
  "edgeStyle":   { "width": 2.5, "lineStyle": "solid", "defaultColor": "#404040",
                   "naming": "fromEndpoints", "labelPlacement": "above" },
  "vertices": [
    { "id": 1, "name": "A", "x": 180, "y": 200, "color": "#E91E63" },
    { "id": 2, "name": "B", "x": 420, "y": 120 }
  ],
  "edges": [
    { "id": 1, "name": "e1", "from": 1, "to": 2, "color": "#9933CC" },
    { "id": 2, "name": "loop", "from": 2, "to": 2 }
  ]
}
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| ~~`canvas.width` / `canvas.height`~~ | 已移除。画布是无限平面，不再写入；旧文件里的会被忽略 |
| `vertexStyle.radius` / `shape` | 所有顶点的半径与形状（`circle` / `square`） |
| `vertexStyle.defaultColor` | 顶点默认颜色 |
| `vertexStyle.naming` | 顶点命名规则：`none` / `alphabetic`（大写字母）/ `numeric`（V+数字） |
| `vertexStyle.labelPlacement` | 顶点名字位置：`inside` / `above` / `below` / `left` / `right` |
| `edgeStyle.width` / `lineStyle` | 所有边的线宽与线型（`solid` / `dashed` / `dotted`） |
| `edgeStyle.defaultColor` | 边默认颜色 |
| `edgeStyle.naming` | 边命名规则：`none` / `alphabetic`（小写字母）/ `numeric`（e+数字）/ `fromEndpoints`（两端点名字） |
| `graph.multi` | 是否多重图（允许重边与自环） |
| `graph.directed` | 是否有向图（边在终点画箭头） |
| `edgeStyle.labelPlacement` | 边名字位置：`inside` / `above` / `below` |
| `vertices[].id` | 顶点唯一编号（整数，必须为正） |
| `vertices[].name` / `x` / `y` | 名字与位置（图像坐标，原点在左上角） |
| `vertices[].color` | 可选；省略表示使用默认颜色 |
| `edges[].from` / `to` | 端点顶点 Id；`from == to` 表示自环 |
| `edges[].name` / `color` | 名字与可选颜色 |

读取时的容错行为：

- 缺失字段使用默认值（例如没有 `canvas` 时按 1200 × 800 处理，
  没有命名/位置字段时按 `alphabetic` + `inside` / `fromEndpoints` + `above` 处理）
- 端点不存在的边会被丢弃，避免出现悬空引用
- 非法颜色值会被忽略，回退到默认颜色
- 内容不是合法 JSON 时会给出可读的错误提示

### 6.2 SVG 导出

导出**只包含图内容的最小矩形**（不再是整个画布）：`viewBox` 等于内容外接矩形向四周扩展
`SvgExport.Padding` 像素（默认 **12**）。内容为空时退回到画布尺寸字段。

- 背景：一张覆盖整个导出区域的白色矩形
- 边：`<line>`（直线）或 `<path>`（多重边、自环），带 `stroke-width` 与 `stroke-dasharray`
- 顶点：`<circle>` 或 `<rect>`
- 名字：`<text>`；位置与画布内一致（内部 / 外部），边标签沿边方向倾斜、**无背景**（深灰字直接压在线上）
- 文本按 XML 规则转义，顶点颜色亮度自动决定文字用黑或白

留白像素数可在代码里改 `SvgExport.Padding`（默认 12）。

### 实现要点

- **自绘画布**：所有图元素都用 GDI+ 直接绘制，因此缩放、样式统一、SVG 导出完全可控。
- **线宽与字号反缩放**：绘制时把画笔宽度与字号乘以 `1/zoom`，使它们在不同缩放下保持视觉一致。
- **右键手势对齐 draw.io**：右键拖动即平移画布。为避免「按下时的轻微手抖被当成拖动」，加了
  `RightHoldMilliseconds = 50` 的**起手延迟**（`System.Windows.Forms.Timer`，间隔 10ms 累计）：
  延迟过后一移动就开始平移；延迟内松手、或延迟过后**始终没有移动**，抬手都弹右键菜单。
- **平移基准点取「越过延迟那一刻的光标位置」**，不是按下时的位置：否则起手阶段累积的位移会在
  第一帧被一次性算进平移量，画面瞬移。实现上第一帧只用于记录基准点，位移从第二帧开始按增量累计。
- **无限画布（draw.io 模型）**：没有纸张、边框与「画布尺寸」。`.graph` 里不再写 `canvas.width/height`，读取旧文件时忽略这两个字段，坐标也不做任何钳制。
  绘制坐标即世界坐标，`_offsetX/_offsetY` 是视口左上角对应的坐标；滚动条**取值范围**由
  「内容外接矩形 ∪ 以视口原点为中心的一屏余地」给出，因此空图时不会出现滚动条，
  有内容时才出现，且始终能滚到内容之外约一个视口，方便把内容移到视野中央。
- **滚动条可见性用内容外接矩形判断**：`NeedsScroll` 比较 `ContentExtent` 与「视口对应的坐标区间」，
  而不是比较内容跨度 —— 否则内容很小但离视口很远时会漏判。
- **框选的边按端点决定**：只有两个端点都被框中的边才被选中（与剪贴板的诱导子图语义一致）。
  顶点仍按「是否与选框相交」判断，`SegmentIntersectsRect`（Liang-Barsky）继续用于几何自检。
- **剪贴板用「诱导子图」语义**：复制只带两端点都被选中的边；剪切额外删除所有与选中顶点相连的边。
  粘贴时重建顶点映射表，避免旧 Id 造成悬空引用，名字冲突自动加编号。
- **滚动条**：自建 `HScrollBar` / `VScrollBar`，仅当内容超出视口时显示；缩放时以光标为锚点调整偏移并同步滚动条。
- **模型与视图分离**：`GraphCanvas` 不依赖任何 UI 类型，可被自检程序直接测试；`CanvasControl` 只负责渲染与交互。
- **无第三方依赖**：JSON 读写、图标生成、着色处理全部自行实现，仅依赖 .NET Framework 自带程序集。

## 10. 常见问题

### 启动时弹出「Microsoft Defender SmartScreen 阻止了无法识别的应用」

这是**预期现象**，不是程序有问题：`build.ps1` 每次都用 `csc.exe` 在本地新编译出一个 `.exe`，
它是**未签名**且**没有下载信誉**的，Defender 对这类文件一律按「未知发布者」拦截。

处理方式：点弹窗里的 **「更多信息」** → 右下角出现 **「仍要运行」** → 点它即可，Windows 会记住这个选择。

排查用的确认命令：

```powershell
# 是否有「从网络下载」标记（本程序应为空）
Get-Item .\build\GraphEditor.exe -Stream Zone.Identifier -ErrorAction SilentlyContinue

# 签名状态（本程序为 NotSigned）
Get-AuthenticodeSignature .\build\GraphEditor.exe | Select-Object Status
```

为什么不加自签名证书：自签名证书只能让**本机**把程序认成「已验证的发布者」，
SmartScreen 的信誉是全球性的，自签名对外无效——换台电脑、或从网上下载，仍然会被拦。
真正消除提示需要 **EV 代码签名证书**并签名，对自用工具通常不划算。

### 「无法加载文件 … 因为在此系统上禁止运行脚本」

系统的 PowerShell 执行策略是 Restricted。按本文档的方式调用即可（只对本次进程放开策略）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

不要为了跑脚本而把全局执行策略改成 `Unrestricted`。

### 排查滚动 / 视图问题的诊断开关

程序支持几个只用于排查的启动参数（正常使用不需要）：

| 参数 | 作用 |
| --- | --- |
| `/diag` | 在状态栏右下角实时显示：视图原点、滚动条位置、可滚动上限、缩放 |
| `/diaglog:路径` | 每 120ms 把上述状态追加写入指定文件 |
| `/dump:路径` | 启动后把工具栏宽度与滚动映射写成一个文本文件 |
| `/open:路径` | 直接打开指定的 `.graph` 文件 |

```powershell
# 实时读数
.\build\GraphEditor.exe /diag

# 读数落盘，便于回看
.\build\GraphEditor.exe /diag /diaglog:D:\temp\scroll.log
```

在 `/diag` 模式下按 **F12** 会把当前视图状态写入程序目录的 `scroll-state.txt`，内容包括缩放、视口尺寸、
视图原点、滚动条位置、以及**视口顶部/底部对应的坐标**（`visibleImageTop` / `visibleImageBottom`），
用来核对滚动方向非常直接。

### 双击 `.graph` 文件没有用 GraphEditor 打开

先运行一次文件关联注册（只写当前用户，不需管理员）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\register-filetype.ps1
```

若图标没立刻刷新，注销再登录一次，或手动在「默认应用」里指定。
